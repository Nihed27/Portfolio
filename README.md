# Nihed Missar — Portfolio

Portfolio interactif bilingue (FR/EN) — élève ingénieure **Software & AI** à l'ENICarthage.

🔗 **En ligne :** https://nihed27.github.io/Portfolio/

## Stack
- HTML / CSS / JavaScript vanilla — aucun framework, aucune étape de build
- Canvas 2D pour les animations (signal LoRa du hero)
- i18n maison (FR/EN), thème clair/sombre, animations au scroll

## Structure
```
index.html
assets/
  css/style.css   # design system + sections
  js/i18n.js      # dictionnaires FR/EN
  js/main.js      # navigation, thème, langue, animations
```

## Lancer en local
Ouvrir `index.html` dans le navigateur, ou :
```bash
python -m http.server 8000
```
